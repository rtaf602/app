# ศูนย์รวมระบบงาน ฝูง.602

หน้ารวมไอคอนของทุกระบบของ ฝูง.602 บน.6 อยู่ที่ `https://rtaf602.github.io/app/`

ทุกคนต้องเข้าสู่ระบบกลางของฝูง (repo `eadmin`) ก่อน ถ้าเบราว์เซอร์ยังไม่ได้เข้าสู่ระบบ หน้านี้จะพาไปหน้าเข้าสู่ระบบ `/eadmin/index.html?next=/app/` และพากลับมาเมื่อเข้าเสร็จ
การเข้าสู่ระบบหนึ่งครั้งใช้ได้ทุกระบบบน `rtaf602.github.io` ตามกติกาของระบบกลาง (1 ชั่วโมง, หนึ่งบัญชีหนึ่งเครื่อง)

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าทั้งหมด: ตรวจการเข้าสู่ระบบ, ไอคอนแต่ละระบบ, แถบหมวด, ค้นหา, ใช้ล่าสุด, โหมดผู้พัฒนา |
| `hero-plane.jpg` | รูปเครื่องบินในแบนเนอร์ |
| `manifest.webmanifest`, `icons/` | ชื่อ (OPERATION) และไอคอนเมื่อกด "เพิ่มลงหน้าจอหลัก" หรือติดตั้งแอป |

หน้านี้โหลด `/eadmin/assets/config.js` และ `/eadmin/assets/app.js` จาก repo `eadmin` ถ้า repo นั้นย้ายหรือปิด GitHub Pages หน้านี้จะแจ้งว่าใช้งานไม่ได้

## เพิ่มหรือแก้ระบบ

แก้ `GROUPS` ใน `index.html` (ค้นคำว่า `รายชื่อระบบ`) แต่ละระบบมี

- `slug` ชื่อ repo เช่น `logbook` (ลิงก์จะเป็น `/logbook/`)
- `short` ชื่อใต้ไอคอน, `title` ชื่อเต็ม, `kw` คำที่ค้นหาได้
- `badge` แบบเครื่องบนไอคอน (ถ้ามี)

## โหมดผู้พัฒนา

ปุ่มมุมขวาบนถามรหัสผ่านก่อนให้ลิงก์ไปหน้า `/eadmin/` หน้าเว็บเก็บเฉพาะค่า SHA-256 ของรหัส (`DEV_HASH` ใน `index.html`) ไม่เก็บรหัสจริง

เปลี่ยนรหัส: หาค่า SHA-256 ของรหัสใหม่ (เช่น พิมพ์ `printf '%s' 'รหัสใหม่' | sha256sum` ในเครื่องที่มี Terminal) แล้วใส่แทนค่าเดิมใน `DEV_HASH`

รหัสนี้กันได้แค่คนที่กดเล่น เพราะหน้าเว็บเป็นสาธารณะ สิ่งที่กันคนนอกจริงคือการเข้าสู่ระบบกลาง และการตรวจสิทธิ์ของแต่ละระบบ
